# 実技ルーブリック実機確認チェックリスト（v1.15.0 / Phase 1）

対象: 体育「実技ルーブリック採点」Phase 1（ソフトバレー・マット運動）
実施場所: 体育館・プールサイド（iPad・片手操作前提）
仕様書: `PE_RUBRIC_SPEC.md` §7.5

教員が実際に触る順序（課題登録 → 単位選択 → 入力カード → 基準編集 → 未確定バナー）で並べています。うまく動かなかった項目はチェックせずに残しておけば、そのまま v1.15.1 の調整対象メモになります。

---

## 1. 課題登録・単位選択

記録入力 → 課題管理タブでの操作。

- [ ] **単位セレクトの選択肢** → 実技記録の単位セレクトに「🏐 ソフトバレー」「🤸 マット運動」が並んで表示される
- [ ] **選択時の自動固定** → どちらかを選ぶと観点が「知識・技能」に自動固定されて編集不可になり、方向/計測欄が消え、「換算未対応」警告が出ない
- [ ] **登録後の一覧表示** → 課題一覧に「採点基準」ボタンが追加される（なわとび等の「換算表」ボタンと並んで表示）

## 2. 入力カード — ソフトバレー（trial × table）

5方向の○×タップ。

- [ ] **カードのレイアウト** → 児童1人につき1枚のカードが縦に並び、判定基準（センターサークル・5m・山なり等）の注記が見える
- [ ] **5方向のラベル** → ①真正面〜⑤後ろ寄りのボタンが個別ラベル付きで並ぶ（44px角以上、片手タップしやすい大きさ）
- [ ] **3状態タップ** → 1回目のタップで○（緑）、2回目で×（グレー）、3回目で未実施（枠線のみ）に戻る
- [ ] **確定タイミング** → 5方向すべてタップするまでは「入力中」バッジのまま。5つ揃った瞬間に「✓ 確定」バッジと緑のカードに変わる

## 3. 入力カード — マット運動（level × average）

4項目のレベル選択 + 加点。

- [ ] **4項目のボタン列** → ①〜④それぞれにレベルボタン（未達成／基本／発展など）が並び、選択中のボタンだけ色が変わる
- [ ] **加点の扱い** → 加点2つ（大きな前転・前方倒立回転跳び）は「挑戦した子だけでOK」の注記付きで別枠に表示される
- [ ] **確定条件** → 4項目すべて選ぶまで確定しない。加点を一切タップしなくても、4項目が揃えば確定する
- [ ] **リアルタイム表示** → タップ直後に各項目の得点とカード下部の合計点が即座に更新される

## 4. 採点基準の編集

課題一覧「採点基準」ボタンからのモーダル操作。

- [ ] **モーダルの内容** → 種目に応じたフォームが開く（ソフトバレーは成功数→点数の換算表、マットはレベルごとの点数）。「本校の実態に応じた目安」の注記が出る
- [ ] **保存後の再計算** → 保存すると、既に確定していた児童の点数が新しい基準で自動的に再計算される
- [ ] **未完了児童への影響** → 入力途中の児童は、基準を変えても確定しない（点数が新たに書き込まれない）

## 5. 未確定バナー

教員向け入力画面限定の警告表示。

- [ ] **表示条件** → 未確定（未入力・入力途中）の児童がいる間、入力画面の上部にオレンジ色のバナーが出て名前が並ぶ
- [ ] **解消の反映** → 1人確定させるたびに名前が消え、全員確定すると自動的にバナーごと消える
- [ ] **表示範囲** → このバナーは記録入力画面にしか出ない。通知表出力・保護者面談PDF・児童向け画面には一切表示されない

## §7.5 実機確認項目（自動テスト対象外）

- [ ] **タップ精度** — iPad Air M4 横向き・Smart Keyboard Folio装着状態で、5方向/4項目のボタンを狙い通りにタップできるか（誤タップの起きやすいボタンがないか）
- [ ] **片手操作の速度** — 体育館・プールサイドで片手操作した場合、ソフトバレーの5タップ・マットの4タップ+加点が現実的な速度で入力できるか
- [ ] **オフライン動作** — 機内モード/Wi-Fiオフの状態で、PWAキャッシュから正常に起動し、入力・保存・基準編集モーダルが問題なく動作するか
